## 📌 Project Overview

The Job Market Analysis project focuses on analyzing employment trends, salary patterns, job opportunities, company information, and in-demand technical skills.

The objective is to understand which job roles are most frequently advertised, which industries have the highest hiring activity, which locations offer better salary opportunities, and what technical skills companies require.

This project uses MySQL for data inspection and cleaning, Microsoft Excel for data preprocessing and analysis, and Power BI for interactive data visualization.

## 🎯 Project Objectives

- Identify locations with the highest number of job postings.
- Analyze average minimum and maximum salaries across locations.
- Identify industries with the highest job opportunities.
- Find companies with maximum job openings.
- Identify the most demanded job titles.
- Analyze salary trends by job title and location.
- Identify technical skills required by companies.
- Understand the relationship between salary and education.
- Develop an interactive Power BI dashboard.
- Generate meaningful business insights and recommendations.

## 📂 Dataset Description

The dataset contains **742 job postings and 42 original features**.

It includes information about:

- Job Titles
- Salary Estimates
- Company Names and Ratings
- Locations and Headquarters
- Industries and Sectors
- Company Size and Age
- Education Requirements
- Technical Skills

**Database:** `project_job_market_analysis`  
**Table:** `Market`

## 🔄 Project Workflow

1. **Data Collection:** Retrieved the job market dataset from the provided MySQL database.
2. **SQL Data Cleaning:** Checked missing values, duplicate combinations and unavailable values.
3. **Excel Data Cleaning:** Cleaned company names, handled missing values and removed unnecessary columns.
4. **Exploratory Data Analysis:** Analyzed job postings, salaries, industries, locations and skills.
5. **Pivot Table Analysis:** Created summaries and comparisons using Excel.
6. **Power BI Dashboard:** Developed interactive visualizations and KPI cards.
7. **Insights & Recommendations:** Identified important job market trends and business recommendations.

## 📊 Power BI Dashboard

- Total Job Postings

- Average Maximum Salary
- Average Salary
- Industry-wise Job Postings
- Sector-wise Job Postings
- Top Job Titles
- Job Locations
- Salary Analysis

Interactive slicers allow users to filter the dashboard by Industry, Location and Job Title.

**Dashboard File:** `JOB MARKET ANALYSIS DASHBOARD(1).pbix`

## 💡 Business Recommendations

1. Job seekers should focus on Python, Excel and SQL to improve their career opportunities.
2. Candidates should explore high-demand roles such as Data Scientist and Data Engineer.
3. Job seekers should compare salary estimates and job availability across different locations.
4. Employers should monitor hiring trends in Information Technology and Biotech & Pharmaceuticals.
5. Companies should use job-title-specific and location-specific salary benchmarks for recruitment planning.
6. Recruitment platforms should improve the completeness and accuracy of job information.
